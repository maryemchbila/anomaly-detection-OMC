# anomaly-detection-OMC
Système de détection d'anomalies et de maintenance prédictive basé sur les données OMC des réseaux LTE. Combine Isolation Forest, Autoencoder LSTM, XGBoost et N-HiTS pour analyser ~2M d'observations, calculer un Health Score par cellule et générer des alertes intelligentes via un dashboard Streamlit.
